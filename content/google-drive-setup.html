Windows 11/10 & macOS — clean setup with four master folders pinned everywhere

What you get: One-click access to Google Drive on both systems. Four tidy root folders pinned in Quick Access (Windows) and Finder Sidebar (Mac). No stray Documents/Pictures clutter in OneDrive.

0 — Why These Four Folders

The same folder structure across every device.

FolderWhat Goes Here
School WorkCoursework, notes, assignments, research. Anything academic.
ProfessionalWork projects, career documents, resumes, internship materials.
LearningPersonal education — your reference docs, book notes, courses, skill-building.
PersonalLife admin, finances, health, travel, personal projects.
Streaming vs. Mirroring: Use Mirror files on Windows only — it unlocks the G: drive letter. macOS works without switching this setting.

Step 1 — Download & Install Drive for Desktop

Same download link for both platforms.

Browser → https://drive.google.com/drive/download

Windows

1. Click Download Drive for desktop → run installer → Yes at UAC → Install.

2. Triangle icon appears in system tray → click Sign in → enter Google account.

3. Drive is now running in the background.

macOS

1. Download GoogleDrive.dmg → double-click DMG → drag Google Drive → Applications.

2. Launch Google Drive → grant Full Disk Access when prompted → Sign in.

3. Finder automatically adds Locations → Google Drive once signed in.

Mac check: If Google Drive doesn't appear in Finder sidebar, go to Finder → Settings → Sidebar → tick Google Drive.

Step 2 — Windows Only: Turn Drive into G:

This step gives you a proper drive letter in File Explorer.

1. Click ▲ in system tray → Google Drive triangle → Preferences.

2. Left column: Google Drive → select Mirror files.

3. Drive letter dropdown → choose G: → Save (Drive restarts).

4. Open File Explorer → This PC now shows Google Drive (G:).

macOS users: skip this entire step. Google Drive already appears as a Location in Finder — no additional configuration needed.

Step 3 — Create Four Master Folders

Do this inside My Drive (the root), on both platforms.

Inside My Drive, create exactly these four folders — in this order:

Folder NameNotes
01_School WorkPrefix numbers to force alphabetical sort order — keeps them in the right sequence everywhere.
02_ProfessionalSame naming convention — consistent across Windows, macOS, and Google Drive web.
03_LearningYour reference docs, book notes, courses, skill-building materials.
04_PersonalLife admin, finances, health, travel, hobbies.
Use the number prefix (01_, 02_, etc.) — it forces alphabetical sort to keep them in order on every device and in every view. Without it, alphabetical order may not match your intended priority order.

Step 4 — Pin Folders for One-Click Access

Do this on each machine after creating the folders.

Windows — Quick Access

1. Open G: in File Explorer.

2. Right-click each of the four folders → Pin to Quick Access.

3. (Optional) Rename the pins with numbers to lock order: ① School Work, ② Professional, etc.

Stop Windows auto-pinning junk: File Explorer → ... → Options → Privacy → untick both 'Show recently used files' and 'Show frequently used folders' → Clear.

macOS — Finder Sidebar

1. Open Locations → Google Drive in Finder.

2. Drag the four folders into Favorites (top of sidebar).

3. Re-order by dragging. Add a folder named ----- as a visual divider if you want separation.

Step 5 — Optional: OneDrive Trim (Windows)

Prevent OneDrive from cluttering your Documents and Pictures.

1. Right-click OneDrive cloud icon → Settings → Sync & backup → Manage backup.

2. Desktop = On, Documents = Off, Pictures = Off.

3. In OneDrive root, create a folder named Archive-2025.

4. Drag old Documents and Pictures content there → right-click → Free up space (moves to cloud only).

Why: By turning off Documents and Pictures backup in OneDrive, you stop the two systems from competing. Everything important lives in Google Drive. OneDrive just syncs Desktop as a safety net.
