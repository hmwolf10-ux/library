How Gmail is different: Labels are tags, not folders — one email can have five. Search is the primary navigation tool. Filters run the moment mail lands. Tabs or Priority Inbox handle 50% of triage automatically before you do anything.

Phase 2 — Mass Purge

20 minutes. Slash dead weight before organizing.

1. Kill marketing bloat: Search: unsubscribe OR "manage preferences" → Select All → click Unsubscribe banner.

2. Delete ancient promos: Search: category:promotions older_than:365d → Select all → Trash.

3. Clear heavy attachments: Search: larger:10M → download keepers (triangle icon) → delete the thread.

Net effect: storage and mental load drop 30–70% from this step alone.

Phase 4 — Build & Color Labels

5 minutes of clicking.

1. Create parent label: Sidebar → + → type name.

2. Create child label: Sidebar → + → name → tick 'Nest label under' → select parent.

3. Set color: Hover label → ⋮ → Label color → pick. Use red for Action Now, green for Bills, grey for Quiet.

4. Set visibility: Hover label → ⋮ → Show if unread (for Quiet parent to auto-hide when empty).

Phase 5 — Train the Important Marker

7-day habit. Takes 30 seconds per day.

Gmail's Important marker (yellow tag) learns from your behavior. Training it properly makes Priority Inbox and notifications dramatically more accurate.

• Mark as Important: Open any email → click the yellow tag → or press = keyboard shortcut.

• Mark as Not Important: Same — click tag to toggle off. Do this aggressively on automated/newsletter emails.

• For 7 days: every time you check email, spend 30 seconds correcting any mis-tagged items.

After 7 days of corrections, Gmail's accuracy exceeds 90% for most inboxes. This directly controls which notifications fire on mobile.

Phase 6 — Write Filters Like a Pro

Filters are the automation engine of Gmail.

How to Create a Filter

1. Open filter builder: Settings → Filters and Blocked Addresses → Create new filter.

2. Write the search: Use the From, Subject, Has words fields. Test by clicking 'Search' first.

3. Set the action: Choose Skip Inbox, Apply label, Delete it, etc. → Create filter.

4. Apply to existing mail: Tick "Also apply filter to matching conversations" → Create.

OR / AND Syntax

• from:(@chase.com OR @fidelity.com) Multiple senders:

• -subject:important Exclude a word:

• from:{@chase.com @fidelity.com} Curly brace shorthand:

4. Body: Include who to contact for urgent items and where to reach them (Slack channel, colleague email).

Appendix C — Auto-Clean Script (Fully Commented)

Paste this into script.google.com → New Project

Edit the RULES array — change label names and maxDays to match your setup. trash: true moves to Trash (recoverable for 30 days). trash: false archives instead.

/**

* RULES array:

* label — exact Gmail label name (case-sensitive)

* maxDays — age threshold in days

* trash — true = move to Trash, false = Archive

*/

const RULES = [

{ label: 'Quiet/Newsletters-Investing', maxDays: 30, trash: true },

{ label: 'Quiet/Promos-Clothes', maxDays: 15, trash: true },

{ label: 'Archive/Receipts', maxDays: 365, trash: false },

];

function autoClean() {

const ONE_DAY = 24 * 60 * 60 * 1000;

const now = Date.now();

RULES.forEach(rule => {

const lbl = GmailApp.getUserLabelByName(rule.label);

if (!lbl) return; // skip if label doesn't exist

lbl.getThreads().forEach(thread => {

const age = (now - thread.getLastMessageDate().getTime()) / ONE_DAY;

if (age > rule.maxDays) {

rule.trash ? thread.moveToTrash() : thread.moveToArchive();

}

});

});

}

1. Paste above into script.google.com → New Project.

2. Run once → click Allow when prompted for permissions.

3. Triggers (clock icon) → Add trigger → daily, 2 AM.

4. Edit RULES anytime — no need to touch the trigger again.
